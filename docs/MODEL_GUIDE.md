# 完整模型阅读指南

## 1. 先建立输入输出概念

阅读 `src/a2g/_initialization.py` 的 `_sequences`，再看 `src/a2g/data.py`。

一个学生的定长序列长度为 200。数据集输出：

- `qseqs/cseqs/rseqs`：原序列位置 0 至 198。
- `shft_qseqs/shft_cseqs/shft_rseqs`：位置 1 至 199。
- `smasks`：参与损失与评估的位置。
- `tseqs`：历史时间戳，保持 int64，避免毫秒整数转换丢失精度。

模型为全部 200 个目标位置产生概率，但损失与 AUC 只使用
`prediction[:, 1:][smasks]`，对齐 `shft_rseqs[smasks]`。
目标 t 的题目和概念已知，当前回答不可见。`hist_r[:, t]` 是 t-1 的回答。
不同学生不共享状态，切片之间不携带状态。

ID 0 是 padding，1 是 OOV，训练折已知 ID 从 2 开始。
`num_c=96/num_q=3109` 表示包含保留 ID 的容量；为保持服务器状态字典，
embedding 仍保留旧实现额外的一行，但该行不得作为数据 ID 使用。

## 2. 按主前向顺序读

`src/a2g/model.py` 的 `A2G.forward` 是完整路径，不必追十几层候选类。

1. 重建目标与严格过去历史，建立首轮概念新颖性 dropout 保护。
2. 查询题目/概念先验，计算因果历史统计与 RWCE。
3. 读取目标和历史 embedding，用训练折支持量缩放稀疏题目残差。
4. 拼接目标、历史、题目、概念、先验和六维学习统计。
5. 折叠归一化输入路径，与语义/证据分流的零起点残差相加。
6. 可选历史时间调制与学生局部有向概念图提供历史特征。
7. Selective SSM 递推得到状态；边界门控制局部状态读出。
8. 四层因果多头注意力，其中前三层有输入门控 FFN。
9. 记忆读出门将 SSM 状态直接加入注意力输出。
10. 尝试次数读出、基础预测头与直接证据形成 base logits。
11. Prequential Newton 仅从更早事件的误差构造当前修正。
12. sigmoid 输出概率，清理暂存 dropout 掩码。

## 3. 各组件对应文件

| 文件 | 作用 | 需要注意 |
| --- | --- | --- |
| `modules/core.py` | SSM、折叠归一化、新颖性 dropout | 这是选择性递推块，不是官方 Mamba 内核 |
| `modules/evidence.py` | 题目可靠度、RWCE、新颖性保护 | 支持量只来自训练折 |
| `modules/attempt.py` | 题目尝试、成功、连续尝试、连续错误 | OOV 不作为同一道真实题目累计 |
| `modules/pace.py` | 历史作答间隔调制 | t 只使用 timestamp[t-1]-timestamp[t-2] |
| `modules/graph.py` | 学生局部有向概念图 GRU 状态 | 图容量排除 padding/OOV |
| `modules/newton.py` | 在线误差的低秩 Newton 修正 | 不把当前标签作为输入 |
| `modules/ffn.py` | 输入相关隐层门 | `2*sigmoid(0)=1`，初始保持原 FFN |
| `modules/input_memory.py` | v39 候选，SSM 投影的过去四步卷积 | 卷积无当前 tap，默认零初始化 |
| `modules/modal.py` | v43 候选，多时间尺度残差 | 与原状态作差后叠加，收益尚未确认 |

## 4. 为什么没有完全重写初始化

`_initialization.py` 保留旧随机流，包括构建后删除的位置 embedding、
末层 FFN 初始化、折叠归一化等。直接删掉这些初始化动作会改变后续权重，
从而不再是同一个 seed42 参考模型。

折叠归一化保持“原参考宽度中部分通道为零”的数学计算，不等同于对缩小后的
通道重新做普通 LayerNorm。学习阶段不要把它替换成普通 Linear/LayerNorm。

附加模块中若干输出从零开始。只检查初始化预测不足以验证迁移；
测试会显式激活这些参数，检查预测、梯度和消融。

## 5. 已知语义与待研究问题

- 基础 `_stats` 对已经右移的历史使用严格下三角，排除了最近一步；
  RWCE 则包含历史对角线，对应真实的 t-1 事件。这一差异为保持等价而保留，
  不是当前 v43 训练中的“泄漏”。本地 `v44_aligned_history` 候选单独改为
  包含历史对角线，不改旧 v33/v43 行为；详见 `V44_ALIGNED_HISTORY.md`。
  候选的时序测试不等于 AUC 改进证据。
- `eval()` 会结束一次性概念新颖性 warmup。这是旧行为；
  训练前做额外 `eval()` 会改变首轮训练，必须避免。
- 关闭 SSM 同时去掉主路径和读出中的状态，v43 内部记忆也随之失效。
- 关闭 attention 同时去掉嵌套 FFN 的作用，不能把二者贡献当成完全独立。
- 关闭分支时仍执行部分模块，以保持按模块命名的 dropout 随机子流。
- 单元测试证明迁移与因果边界，不证明教学因果、结构创新或 AUC 提升。

## 6. 后续修改顺序

先运行等价与数据测试，选择一个可解释、可消融的变更，保存新配置及新候选名。
保持数据、seed 和训练协议不变，用独立随机初始化训练。
先判断完整验证集 AUC，再决定是否另行冻结完整消融协议。
不要同时调多个模块，再把全部收益归因于某一个模块。
